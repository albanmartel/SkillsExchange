# Spécifications fonctionnelles
 
**Pour les visiteurs non connectés** l'application permet:
  
- D'afficher la liste des créneaux d'aide proposés par les utilisateurs. 

- Chaque créneau s'affiche dans un paragraphe. A l'intérieur duquel seront affichés :
 - la date,
 - la durée,
 - la compétence,
 - l'activité.
 
-  dans la barre de navigation "header" il y a un bouton de connexion.

**Pour les utilisateurs connectés**, l'application permet : 

- D'afficher la liste des créneaux d'aide proposés par les utilisateurs. Il voit en plus le prénom, le nom et l'adresse courriel de l'utilisateur ce qui n'est pas possible pour le visiteur anonyme.

- D'afficher une liste des compétences de l'utilisateur.

- D'afficher une liste des créneaux où il disponible pour faire aider un utilisateur à réaliser une activité.

- D'afficher une liste des créneaux où il cherche quelqu'un pour l'aider à faire une activité où il n'a pas de compétences.

- D'afficher la liste des créneaux où un autre utilisateur recherche de quelqu'un pour l'aider dans une activité où il a un les compétences.
  - Chaque créneau aura à côté un bouton de validation où l'utilisateur indique qu'il est disponible pour la période de temps concernée.

- Dans la bare de navigation, le bouton connexion est remplacé par le prénom et le nom de l'utilisateur connecté (profil)

- Le bouton du profil masque un menu pour voir le détail du profil et la déconnection.

# Spécifications fonctionnelles
 
**Pour les visiteurs non connectés** l'application permet:
  
- D'afficher la liste des créneaux d'aide proposés par les utilisateurs. 

- Chaque créneau s'affiche dans un paragraphe. A l'intérieur duquel seront affichés :
 - la date,
 - la durée,
 - la compétence,
 - l'activité.
 
-  dans la barre de navigation "header" il y a un bouton de connexion.

**Pour les utilisateurs connectés**, l'application permet : 

- D'afficher la liste des créneaux d'aide proposés par les utilisateurs. Il voit en plus le prénom, le nom et l'adresse courriel de l'utilisateur ce qui n'est pas possible pour le visiteur anonyme.

- D'afficher une liste des compétences de l'utilisateur. 
  - Un bouton pour ajouter, modifier, supprimer une compétence.
  - Un bouton pour ajouter, modifier, supprimer une activité liée à une compétence.

- D'afficher une liste des créneaux où il offre d'aider un utilisateur à réaliser une activité.

- D'afficher une liste des créneaux où il cherche à être aider à faire une activité où il n'a pas de compétences.

- D'afficher la liste de demande de créneaux d'aide de d'autres utilisateurs ou il a un compétence.
  - Chaque créneau afficher aura un bouton de validation pour confirmer sa disponibilité pour le créneau sélectionné.

- D'afficher la liste des futurs créneaux d'activité validés.
  - Si le bouton supprimer est sélectionné alors cela fait apparaître un formulaire avec un champs 
  - Afficher un bouton supprimer avec un texte pour expliquer le pourquoi de la suppression 

- Dans la bare de navigation, le bouton connexion est remplacé par le prénom et le nom de l'utilisateur connecté (profil)

- Le bouton du profil masque un menu pour voir le détail du profil et la déconnection.
